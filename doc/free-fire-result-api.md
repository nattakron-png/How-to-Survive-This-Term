# Free Fire Result API

บันทึกผลเกมของรายการแบบเก็บคะแนน (Free Fire) และดูตารางคะแนนรวม
คะแนนต่อเกม = คะแนนอันดับ (จาก `tournament_placement_points`) + kill × `points_per_kill`
เมื่อบันทึกผลครบทุกเกม (`total_games`) ระบบเปลี่ยนรายการเป็น COMPLETED ให้อัตโนมัติ

## POST /api/v1/free-fire-games/{gameId}/results

กรอกผลของทุกทีมในรายการพร้อมกันในคำขอเดียว

```json
{
  "results": [
    { "teamId": 11, "placement": 1, "kills": 5 },
    { "teamId": 12, "placement": 2, "kills": 3 },
    { "teamId": 13, "placement": 3, "kills": 0 }
  ]
}
```

| Status | เมื่อไร |
| --- | --- |
| 201 | บันทึกสำเร็จ คืนผลของเกมพร้อมคะแนนแต่ละทีม |
| 400 | ไม่ครบทุกทีม, ทีมซ้ำ, ทีมไม่อยู่ในรายการ, อันดับซ้ำหรือเกินจำนวนทีม, kill ติดลบ |
| 404 | ไม่พบเกม |
| 409 | เกมนี้บันทึกผลแล้ว, รายการไม่ได้เป็นแบบเก็บคะแนน |

## GET /api/v1/free-fire-games/{gameId}/results

| Status | เมื่อไร |
| --- | --- |
| 200 | คืนผลเรียงตามอันดับ (ถ้ายังไม่บันทึก `results` เป็นรายการว่าง) |
| 404 | ไม่พบเกม |

## GET /api/v1/tournaments/{tournamentId}/standings

ตารางคะแนนรวมของทุกทีม `pointsPerGame` มีขนาดเท่ากับ `totalGames` และเกมที่ยังไม่แข่งเป็น `null`

เรียงอันดับตาม: คะแนนรวม → จำนวน Booyah (อันดับ 1) → kill รวม → อันดับในเกมล่าสุด

| Status | เมื่อไร |
| --- | --- |
| 200 | สำเร็จ |
| 404 | ไม่พบรายการ |
| 409 | รายการไม่ได้เป็นแบบเก็บคะแนน |
