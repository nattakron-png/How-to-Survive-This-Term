# Match Result API

บันทึกและดูผลของแมตช์แบบแพ้คัดออก เมื่อบันทึกสำเร็จ ระบบส่งผู้ชนะไปแมตช์ถัดไปให้อัตโนมัติ
(ถ้าเป็นนัดชิง ระบบเปลี่ยนรายการเป็น COMPLETED)

## POST /api/v1/matches/{matchId}/result

Request

```json
{ "teamAScore": 2, "teamBScore": 1, "winnerTeamId": 10 }
```

Response `201 Created`

```json
{
  "id": 5, "matchId": 1,
  "teamAId": 10, "teamAScore": 2,
  "teamBId": 20, "teamBScore": 1,
  "winnerTeamId": 10, "createdAt": "2026-10-15T20:42:00"
}
```

| Status | เมื่อไร |
| --- | --- |
| 201 | บันทึกสำเร็จ |
| 400 | คะแนนติดลบหรือไม่ได้ส่งมา, คะแนนเสมอ, ผู้ชนะไม่ใช่ทีมในแมตช์, ผู้ชนะคะแนนน้อยกว่า |
| 404 | ไม่พบแมตช์ |
| 409 | แมตช์มีผลแล้ว, แมตช์ยังมีทีมไม่ครบสองฝั่ง, ช่องในแมตช์ถัดไปมีทีมอื่นอยู่แล้ว |

## GET /api/v1/matches/{matchId}/result

| Status | เมื่อไร |
| --- | --- |
| 200 | พบผล |
| 404 | แมตช์ยังไม่มีผล |

## กติกาการส่งผู้ชนะ

ผู้ชนะจากแมตช์ที่ `match_number` เป็นเลขคี่ไปช่อง A ของแมตช์ถัดไป เลขคู่ไปช่อง B
เมื่อแมตช์ถัดไปรู้ทีมครบสองฝั่ง สถานะเปลี่ยนเป็น SCHEDULED
