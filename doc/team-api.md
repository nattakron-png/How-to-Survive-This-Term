# Team API (schema V1–V8)

Base path: `/api/v1/teams` ข้อมูลทีมตอนนี้มี `id`, `name`, `description`, `createdAt` เท่านั้น ยังไม่มีเกม โลโก้ หรือวันแก้ไขล่าสุด

| Method | Path | ผลลัพธ์ |
|---|---|---|
| GET | `/api/v1/teams?name=phoenix&page=0&size=20&sort=name,asc` | รายการทีมแบบแบ่งหน้า; `name` ค้นหาบางส่วนโดยไม่สนตัวพิมพ์ใหญ่เล็ก |
| GET | `/api/v1/teams/{id}` | รายละเอียดทีม |
| POST | `/api/v1/teams` | สร้างทีม; 201 พร้อม `Location` |
| PUT | `/api/v1/teams/{id}` | แก้ชื่อและคำอธิบายทีม |
| DELETE | `/api/v1/teams/{id}` | ลบทีม; 204 |
| GET | `/api/v1/teams/{id}/players?page=0&size=20` | ผู้เล่นในทีมแบบแบ่งหน้า |
| PUT | `/api/v1/teams/{id}/players/{playerId}` | เพิ่มผู้เล่นที่มีอยู่เข้าทีม หรือย้ายจากทีมเดิม |
| DELETE | `/api/v1/teams/{id}/players/{playerId}` | ถอดผู้เล่นออกจากทีม; ผู้เล่นยังอยู่ในระบบ |

ตัวอย่าง request สำหรับ POST และ PUT:

```json
{
  "name": "Team Phoenix",
  "description": "ทีมจากคณะวิศวกรรมศาสตร์"
}
```

`name` ต้องไม่ว่างและยาวไม่เกิน 150 ตัวอักษร ระบบตัดช่องว่างต้นและท้ายก่อนบันทึก และปฏิเสธชื่อซ้ำโดยไม่สนตัวพิมพ์ใหญ่เล็ก `description` เว้นว่างได้ PUT เป็นการแทนข้อมูลทั้งชุด จึงส่ง `description` มาด้วยหากต้องการเก็บค่าเดิม

รายการแบบแบ่งหน้าตอบเป็น `{ "content": [...], "page": 0, "size": 20, "totalElements": 1, "totalPages": 1 }` ค่าเริ่มต้นเรียงตามชื่อทีม/ผู้เล่น

กรณีผิดพลาด: 400 เมื่อ request ไม่ผ่าน validation, 404 เมื่อไม่พบทีม/ผู้เล่นหรือความสัมพันธ์ที่ต้องการถอด, 409 เมื่อชื่อทีมซ้ำหรือการลบขัดกับ foreign key ของข้อมูลการแข่งขัน รูปแบบ error คือ `{ "message": "...", "timestamp": "..." }`

การลบทีมทำให้ `players.team_id` เป็น `NULL` ตาม V4 ผู้เล่นไม่ถูกลบ ถ้าทีมถูกอ้างอิงโดย match หรือผลแข่ง ฐานข้อมูลจะไม่ให้ลบ ส่วนความสัมพันธ์ `tournament_teams` ใช้ cascade ตาม V6 ควรทบทวนนโยบายการลบทีมเมื่อพัฒนาส่วน Tournament

การสร้าง/แก้ข้อมูลผู้เล่นโดยตรง, การกรองตามเกม, โลโก้ และสิทธิ์ Admin ยังไม่อยู่ใน API ชุดนี้ ต้องทำต่อเมื่อทีมกำหนด schema และการเข้าถึง
