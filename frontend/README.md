# Frontend (Vue 3 + Vite)

UI ดิบตาม Figma ใช้ mock data ใน `src/mock/` ยังไม่เชื่อม backend

## รัน
```bash
cd frontend
npm install
npm run dev
```
เปิด http://localhost:5173

## โครงสร้าง
- `src/views/` — แต่ละหน้า
- `src/components/` — ชิ้นส่วนที่ใช้ซ้ำ
- `src/mock/` — ข้อมูลตัวอย่าง
- `src/router/index.js` — กำหนด URL ของแต่ละหน้า
